# Datasets

This folder contains the datasets used in the Customer Journey & Conversion Analytics project.

## Files

- **online_shoppers_intention.csv** – Original dataset downloaded from the UCI Machine Learning Repository.
- **online_shoppers_cleaned.csv** – Cleaned and preprocessed dataset used for Exploratory Data Analysis (EDA), SQL analysis, Power BI dashboard, A/B Testing, and Machine Learning.

## Dataset Information

- Total Records: 12,330
- Total Features: 18
- Target Variable: Revenue
  - TRUE = Purchase
  - FALSE = No Purchase

The cleaned dataset includes preprocessing such as:
- Missing value handling (if applicable)
- Data type corrections
- Feature engineering
- Data cleaning for machine learning
