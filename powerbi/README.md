# Power BI Dashboard

This folder contains the interactive dashboard developed for business users.

## Dashboard Pages

- Executive Summary
- Customer Segmentation
- Conversion Analysis
- Traffic Source Analysis
- Funnel Analysis
- Monthly Performance
- Visitor Behaviour

## KPIs

- Total Visitors
- Purchases
- Conversion Rate
- Returning Visitors
- Weekend Conversion
- Revenue Contribution

The dashboard enables business stakeholders to monitor customer behaviour and identify opportunities to improve conversion rates.
