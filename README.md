# Customer-Journey-Conversion-Analytics
# 🛒 Customer Journey & Conversion Analytics
> **End-to-End Data Analytics & Machine Learning Project**  
> Predicting online purchase behaviour and uncovering customer insights using **SQL, Python, Power BI, A/B Testing, and Machine Learning**.

---

## 📌 Project Overview

Understanding customer behaviour is critical for improving online conversion rates. In this project, I analysed customer browsing patterns, traffic sources, visitor behaviour, and purchasing trends to identify the factors influencing online purchases.

The project combines **Business Intelligence**, **Statistical Analysis**, and **Machine Learning** to provide actionable insights and predict whether a visitor is likely to make a purchase.

---

## 🎯 Business Objective

The objective of this project is to help an e-commerce business answer questions such as:

- Which customers are most likely to convert?
- Which traffic sources generate the highest conversion rates?
- How does visitor behaviour influence purchases?
- Does browsing activity differ between buyers and non-buyers?
- Which customer segments should be targeted through marketing campaigns?
- Can machine learning accurately predict purchase intent?

# 📊 Dataset

**Source:** UCI Machine Learning Repository

**Dataset Name:** Online Shoppers Purchasing Intention Dataset

### Dataset Summary

- Total Records: **12,330**
- Features: **18**
- Target Variable: **Revenue**
- Problem Type: **Binary Classification**

Target Variable:

- TRUE → Purchase
- FALSE → No Purchase

# 🏆 Results

The tuned **XGBoost** model delivered the best overall performance by balancing precision and recall while achieving a strong ROC-AUC score.

The model can assist businesses in identifying high-intent visitors and improving marketing efficiency.
